# Changelog

All notable changes to DRUID will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/),
and this project adheres to [Semantic Versioning](https://semver.org/).

## [0.1.0] — 2026-05-19

### Added

- Initial release.
- Multi-format data loading (CSV, Parquet, Excel, JSON, BigQuery, PostgreSQL).
- AI-powered schema inspection with OpenAI, Anthropic, and Google providers.
- Automated EDA: statistical profiling, distribution plots, correlation analysis.
- AI-generated insights and EDA guidance.
- Preprocessing pipeline: cleaning, imputation, outlier treatment, datetime features, encoding.
- Model experimentation: trains and ranks 7+ algorithms automatically.
- XGBoost and LightGBM included when installed.
- AI-powered model recommendations.
- Session tracking and reproducible script export.
- Rich console output.
