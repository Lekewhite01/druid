API Reference

Complete reference for all public DRUID functions and classes.

druid.configure()

druid.configure(provider, api_key=None, model=None, **kwargs)
Configure DRUID's AI provider and global settings.
ParameterTypeDescription
providerstr"openai", "anthropic", or "google".
api_keystr | NoneAPI key. Falls back to environment variables if omitted.
modelstr | NoneModel name override (e.g. "gpt-4o", "claude-sonnet-4-20250514").

Returns: DruidConfig — the updated global configuration.

druid.load()

druid.load(source, target=None, name=None, **kwargs)
Load data from any source into a DruidDataset.
ParameterTypeDescription
sourcestrFile path, BigQuery table reference, or SQL query string.
targetstr | NoneName of the target / label column.
namestr | NoneHuman-friendly dataset name. Auto-generated if omitted.
**kwargsPassed to the underlying loader (e.g. sheet_name for Excel).

Returns: DruidDataset

Auto-detects format from the source string: CSV, TSV, Parquet, Excel, JSON, JSONL, Feather, BigQuery table references, and SQL queries.

druid.inspect()

druid.inspect(ds)
AI-powered schema inspection.
ParameterTypeDescription
dsDruidDatasetThe dataset to inspect.

Returns: dict with keys profile and raw_response (AI commentary, or None if AI is not configured).

druid.explore()

druid.explore(ds, question=None, save_dir=None)
Exploratory data analysis with optional AI guidance.
ParameterTypeDescription
dsDruidDatasetThe dataset to explore.
questionstr | NoneSpecific question to focus the AI's commentary.
save_dirstr | NoneDirectory to save plot images.

Returns: dict with keys profile, plots, and optionally ai_guidance.

druid.prepare()

druid.prepare(ds, auto=True)
Preprocess the dataset for modelling.
ParameterTypeDescription
dsDruidDatasetThe dataset to preprocess.
autoboolIf True, uses sensible defaults for the full pipeline.

Returns: DruidDataset — the preprocessed dataset.

druid.experiment()

druid.experiment(ds, task_type=None)
Train multiple models and compare performance.
ParameterTypeDescription
dsDruidDatasetMust have target set.
task_typestr | None"classification" or "regression". Auto-detected if omitted.

Returns: dict with keys leaderboard, best_model, task_type, and per-model results.

druid.recommend()

druid.recommend(ds, experiment_results=None)
Get AI-powered recommendations for next steps.
ParameterTypeDescription
dsDruidDatasetThe dataset.
experiment_resultsdict | NoneResults from druid.experiment().

Returns: str — AI-generated recommendations.

DruidDataset

class druid.DruidDataset
Central wrapper around a pandas DataFrame with metadata, profiling, and session tracking.
AttributeTypeDescription
dfpd.DataFrameThe underlying DataFrame.
namestrHuman-friendly dataset name.
targetstr | NoneName of the target column.
configDruidConfigConfiguration for this dataset.
shapetupleRows and columns (delegates to DataFrame).

Key Methods

MethodDescription
profile(force=False)Compute a statistical profile. Cached unless force=True.
classify_columns()Returns a dict classifying columns into numeric, categorical, boolean, datetime, text, id_like.

DruidConfig

class druid.DruidConfig
Global configuration dataclass.
AttributeTypeDefault
aiAIConfigDefault AIConfig (unconfigured)
displayDisplayConfigDisplay settings
pipelinePipelineConfigPreprocessing defaults

Class Methods

MethodDescription
from_yaml(path)Load configuration from a YAML file.
to_yaml(path)Save configuration to a YAML file (API keys scrubbed).

AIConfig

class druid.AIConfig
AI provider configuration.
AttributeTypeDefault
providerstr"openai"
api_keystr | NoneAuto-resolves from env
modelstr | NoneProvider-specific default
temperaturefloat0.3
max_tokensint2000
is_configuredboolProperty: True if an API key is available.

auto_clean()

druid.preprocessing.auto_clean(dataset, null_threshold=None, constant_tol=0.98)
Full automatic cleaning pipeline: drops high-null columns, constant features, trims whitespace, imputes missing values, removes duplicates.

Returns: DruidDataset

featurize_datetime()

druid.preprocessing.featurize_datetime(dataset, columns=None, features=None, drop_original=True)
Extract temporal features (year, month, day, day of week, hour) from datetime columns using feature-engine.
ParameterTypeDescription
columnslist[str] | NoneColumns to featurize. Auto-detected if omitted.
featureslist[str] | NoneWhich features to extract. Defaults to year, month, day_of_week, hour.
drop_originalboolWhether to drop the original datetime columns.

Returns: DruidDataset

treat_outliers()

druid.preprocessing.treat_outliers(dataset, method="iqr", fold=1.5, columns=None)
Cap outliers using feature-engine's Winsorizer.
ParameterTypeDescription
methodstr"iqr" or "gaussian".
foldfloatIQR multiplier or standard deviation multiplier.
columnslist[str] | NoneColumns to treat. Auto-detects numeric columns if omitted.

Returns: DruidDataset

encode_categoricals()

druid.preprocessing.encode_categoricals(dataset, high_card_threshold=None, drop_first=True)
Automatic categorical encoding. Low-cardinality → one-hot, high-cardinality → frequency encoding.
ParameterTypeDescription
high_card_thresholdint | NoneCardinality cutoff. Defaults to PipelineConfig.high_cardinality_threshold (15).
drop_firstboolDrop first category in one-hot encoding to avoid collinearity.

Returns: DruidDataset

bin_numeric()

druid.preprocessing.bin_numeric(dataset, column, bins, labels=None)
Bin a numeric column into categories using pd.cut().

Returns: DruidDataset

run_experiment()

druid.modelling.experiment.run_experiment(X_train, X_test, y_train, y_test, task_type, dataset=None)
Train multiple algorithms and return a ranked leaderboard.

Trains 7 sklearn models (Logistic Regression, Random Forest, Gradient Boosting, AdaBoost, Decision Tree, KNN, SGD) plus XGBoost and LightGBM if installed. Returns a dict with leaderboard, best_model, and per-model results.

classification_summary()

druid.modelling.evaluator.classification_summary(model, X_test, y_test)
Generate a full classification report with confusion matrix and ROC curve.

Returns: dict with report, confusion_matrix, and matplotlib figures.

feature_importance()

druid.modelling.evaluator.feature_importance(model, feature_names, top_n=20)
Extract and plot feature importances from tree-based or linear models.

Returns: matplotlib Figure

export_script()

druid.utils.export_script(dataset, path)
Export the dataset's session log as a standalone, reproducible Python script.

save_dataset() / load_dataset()

druid.utils.save_dataset(dataset, path)
Pickle the DruidDataset (DataFrame + metadata + session) for checkpointing.
druid.utils.load_dataset(path) → DruidDataset
Reload a saved DruidDataset from a pickle checkpoint.
