Five calls. Full workflow.

Load your data, and DRUID inspects it, surfaces quality issues, recommends preprocessing, generates visualisations, runs model experiments, and explains the results.

  1. Configure your AI provider
  2. Load data from any source
  3. AI inspects the schema
  4. One-line preprocessing
  5. Train & compare models
  6. AI recommends next steps
Python
import druid

# Configure your AI provider
druid.configure(provider="anthropic")

# Load data (auto-detects format)
ds = druid.load("transactions.csv", target="is_fraud")

# AI inspects the schema
druid.inspect(ds)

# Exploratory analysis with AI commentary
druid.explore(ds)

# Preprocess in one line
ds = druid.prepare(ds)

# Train and compare models
results = druid.experiment(ds)

# AI recommends next steps
druid.recommend(ds, results)

Every source. One function.

No boilerplate loaders. Just pass a path, table reference, or SQL query to druid.load() and it handles the rest.

Tip

BigQuery and PostgreSQL require optional extras. Install with pip install druid-ai[bigquery] or druid-ai[postgres].

Python
# Local files — auto-detected
ds = druid.load("data.csv")
ds = druid.load("data.parquet")
ds = druid.load("data.xlsx")
ds = druid.load("data.json")

# BigQuery
ds = druid.load("project.dataset.table")

# SQL query
from druid.loaders import SQLLoader
ds = druid.load(
    "SELECT * FROM users",
    loaders=[SQLLoader(conn_str)]
)

Clean, modular architecture

Three layers: data, reasoning, tasks. Each works independently.

druid/
├── core/   # DruidDataset, config, session tracking
├── loaders/   # File, database, auto-detect loaders
├── ai/   # LLM providers, prompts, schema inspector
├── eda/   # Profiling, visualisation, AI insights
├── preprocessing/   # Cleaning, transforms, encoding
├── modelling/   # Experiments, evaluation, recommendations
└── utils/   # Display, sampling, export helpers
