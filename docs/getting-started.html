Getting Started

Install DRUID and go from raw data to trained models in under five minutes.

Installation

DRUID requires Python 3.9 or later. Install the core package from PyPI:

pip install druid-ai

The core package includes pandas, numpy, scikit-learn, matplotlib, seaborn, feature-engine, missingno, and rich. To add AI provider support, install the relevant extras:

# Pick your provider
pip install druid-ai[openai]       # OpenAI (GPT-4o, GPT-4, etc.)
pip install druid-ai[anthropic]    # Anthropic (Claude)
pip install druid-ai[google]       # Google (Gemini)

# Or install everything
pip install druid-ai[all]

For database connectors:

pip install druid-ai[bigquery]     # Google BigQuery
pip install druid-ai[postgres]     # PostgreSQL (via SQLAlchemy)
Tip

For development, clone the repo and install in editable mode: pip install -e ".[dev]"

AI Configuration

DRUID uses environment variables by default. Set the key for your chosen provider:

# In your shell profile (.bashrc, .zshrc, etc.)
export OPENAI_API_KEY="sk-..."
export ANTHROPIC_API_KEY="sk-ant-..."
export GOOGLE_API_KEY="..."

Then tell DRUID which provider to use:

import druid

# Uses the matching env var automatically
druid.configure(provider="anthropic")

# Or pass the key directly
druid.configure(provider="openai", api_key="sk-...")
Note

AI is optional. DRUID's profiling, visualisations, preprocessing, and model experiments all work without an API key. The AI layer adds natural-language schema analysis, insights, and recommendations.

Loading Data

Pass any file path, table reference, or SQL query to druid.load(). The format is auto-detected:

# Local files
ds = druid.load("transactions.csv", target="is_fraud")
ds = druid.load("users.parquet")
ds = druid.load("report.xlsx", sheet_name="Q4")

# BigQuery
ds = druid.load("myproject.analytics.events")

# SQL with a custom connection
from druid.loaders import SQLLoader
ds = druid.load(
    "SELECT * FROM orders WHERE year = 2024",
    loaders=[SQLLoader("postgresql://user:pass@host/db")]
)

The result is a DruidDataset that wraps your DataFrame with metadata, profiling, and session tracking. Access the raw DataFrame anytime with ds.df.

Schema Inspection

Ask DRUID to analyse the dataset structure. Without AI, this prints a statistical profile. With AI, it sends that profile to the LLM for deeper analysis:

result = druid.inspect(ds)

The AI flags issues like mislabelled columns, suspicious distributions, and potential data leakage — before you write a single line of analysis code.

Exploratory Analysis

Generate visualisations and (optionally) AI-powered commentary on what the data is telling you:

# General exploration
eda = druid.explore(ds)

# Focused question
eda = druid.explore(ds, question="What patterns separate fraud from non-fraud?")

# Save plots to disk
eda = druid.explore(ds, save_dir="./eda_output")

This produces missing-value matrices, distribution histograms, correlation heatmaps, and target-variable analysis.

Preprocessing

One line handles cleaning, imputation, encoding, and outlier treatment:

ds = druid.prepare(ds)

Need more control? Import individual functions:

from druid.preprocessing import (
    auto_clean,
    featurize_datetime,
    treat_outliers,
    encode_categoricals,
    bin_numeric,
)

ds = auto_clean(ds)
ds = featurize_datetime(ds, columns=["created_at"])
ds = treat_outliers(ds, method="iqr", fold=1.5)
ds = encode_categoricals(ds, high_card_threshold=15)

Model Experiments

Train multiple algorithms and get a ranked leaderboard:

results = druid.experiment(ds)

This trains Logistic Regression, Random Forest, Gradient Boosting, AdaBoost, Decision Tree, KNN, and SGD out of the box. If xgboost or lightgbm are installed, those are automatically included.

The leaderboard shows accuracy, F1, precision, recall, ROC AUC, and training time for each model. DRUID auto-detects whether the task is classification or regression from the target column.

AI Recommendations

Send the experiment results to the AI for actionable next steps:

druid.recommend(ds, results)

The AI recommends which model to invest in, specific hyperparameters to tune, and strategies for handling class imbalance or other dataset-specific issues.

Session Tracking

Every DRUID operation is logged as a session event with timestamps, parameters, and AI rationale. Export the full session as a standalone Python script:

from druid.utils import export_script

export_script(ds, "my_pipeline.py")

This produces a reproducible script you can hand to colleagues or run in production — no DRUID dependency required.

YAML Configuration

For team environments, share settings via a YAML file:

# druid_config.yaml
ai:
  provider: anthropic
  model: claude-sonnet-4-20250514
  temperature: 0.3
pipeline:
  null_threshold: 0.7
  high_cardinality_threshold: 15
from druid import DruidConfig

config = DruidConfig.from_yaml("druid_config.yaml")

Using Without AI

DRUID is fully functional without an API key. Skip druid.configure() and every tool works — profiling, visualisations, preprocessing, model experiments. The AI adds schema analysis, natural-language insights, and model recommendations on top.
